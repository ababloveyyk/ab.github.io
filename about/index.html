    你好，我是安柏

    # 你好，我是安柏

    C++ 是信仰，Kali 是玩具，ICPC 赛场我是那个喊"各就位"的人。

    # 关于我

    • 大学在读，主修 网络安全，副修"怎么不被自己写的脚本炸掉"
    • 主力语言：C++（我的神）、PHP（用来换饭）、Python（用来偷懒）
    • 日常军火库：Kali Linux、天狐渗透工具箱、VS Code、Cursor、Trae、Claude —— 主打一个"AI 帮我写，我帮 AI 改"
    • 续命三件套：骑行、跑步、羽毛球（写代码 2 小时，必须出去晃一圈，不然腰椎会报警）

    # 稍微正经一点的成就

    ICPC 陕西省赛 · 总调度 不写代码，但管着上百支队伍的比赛流程。从赛前设备调试到赛后成绩核对，全程精神紧绷，比我自己打比赛还累。收获是：再复杂的系统，归根结底都是"人"和"时间"的调度，这道理写代码和办比赛通用。

    # 安全圈摸爬记

    • 做过网络安全评估，从信息收集到漏洞验证，一路踩坑一路填。
    • 最近沉迷 Kali 工具链，不是为了当黑客，是想搞清楚"敌人怎么进门"，才好给自家大门加锁。

    # 这个博客到底写啥？

    写给面试官看，但更是写给 30 岁以后的自己看。

    我会把每天学到的东西写成 正经教程（毕竟不能误人子弟），但行文里可能夹带私货——比如吐槽某个漏洞蠢得可爱，或者某条命令又把我电脑搞崩了。 当作技术日记，不追求流量，只求以后翻到能想起"哦，那天我调这个 bug 调到凌晨三点"。

    # 遇到不会的怎么办？

    我的三板斧：

    1. GitHub 搜轮子
    2. DeepSeek/ChatGPT 问思路
    3. B站看实操（倍速播放是精髓） 实在不行就睡一觉，梦里灵感比较多。

    # 我想留给别人的印象

    "这哥们儿网安方向确实有两下子，但聊天也挺能扯。" 技术不拉胯，人也不无聊。

    # 一句不负责任的座右铭

    "苦厄难磨凌云志，不死终有出头日。"

    P.S. 如果你看到我的 commit 记录里出现"fix typo"或者"update"，那大概率是我在摸鱼间隙随手改的。别学我。
