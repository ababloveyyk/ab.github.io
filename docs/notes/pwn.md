# PWN 入门指南

## 什么是 PWN

PWN 是 CTF 中的一个重要类别，主要涉及二进制程序的漏洞挖掘和利用。PWN 的目标是通过漏洞获取目标系统的控制权。

## 核心概念

### 缓冲区溢出

缓冲区溢出是最经典的二进制漏洞之一，当程序向缓冲区写入超出其大小的数据时，会覆盖相邻内存区域。

**类型：**
- 栈溢出：覆盖栈上的返回地址
- 堆溢出：利用堆内存管理漏洞

### ROP（Return-Oriented Programming）

ROP 是一种高级漏洞利用技术，通过拼接程序中已有的代码片段（gadget）来执行任意代码。

### Shellcode

Shellcode 是一段用于获取 shell 的机器码，通常是漏洞利用的最终目标。

## 学习路径

1. **基础阶段**：C/C++ 编程、汇编语言、操作系统原理
2. **中级阶段**：调试工具使用（GDB、pwndbg）、漏洞原理
3. **高级阶段**：ROP 链构造、堆漏洞利用、格式化字符串漏洞

## 常用工具

- **GDB / pwndbg**：调试工具
- **objdump**：反汇编工具
- **pwntools**：Python 漏洞利用库
- **IDA Pro**：专业逆向工具
- **radare2**：开源逆向工具

## 保护机制

### ASLR（地址空间布局随机化）

随机化程序加载地址，增加利用难度。

### DEP（数据执行保护）

标记数据段为不可执行，阻止 shellcode 执行。

### Canary

在栈上插入随机值，检测栈溢出。

## 实战建议

- 从简单的栈溢出题目开始
- 熟悉调试工具的使用
- 阅读源码，理解漏洞产生的原因
