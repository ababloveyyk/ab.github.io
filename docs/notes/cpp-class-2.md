## 前言

构造函数和析构函数是C++类中最重要的两个特殊成员函数。构造函数负责对象的初始化，确保对象在创建时处于有效状态；析构函数负责对象的清理，确保资源在对象销毁时被正确释放。这两个函数是C++ RAII（资源获取即初始化）编程范式的核心。

本文将从最简单的默认构造函数开始，逐步深入到带参构造函数、拷贝构造函数、移动构造函数、析构函数、初始化列表和委托构造函数。通过丰富的代码示例，帮助读者全面掌握C++对象的生命周期管理。

## 默认构造函数

### 什么是默认构造函数

默认构造函数是指不需要任何参数就可以调用的构造函数。它可以是无参的构造函数，也可以是所有参数都有默认值的构造函数。

```cpp
#include <iostream>
#include <string>

class Simple {
private:
    int value;
    std::string name;

public:
    // 默认构造函数：无参数
    Simple() : value(0), name("Default") {
        std::cout << "Simple() 默认构造函数被调用" << std::endl;
    }

    void display() const {
        std::cout << "Simple: value=" << value << ", name=" << name << std::endl;
    }
};

class WithDefaults {
private:
    int x, y;
    std::string label;

public:
    // 所有参数都有默认值，也是默认构造函数
    WithDefaults(int x = 0, int y = 0, const std::string& label = "Point")
        : x(x), y(y), label(label) {
        std::cout << "WithDefaults(" << x << ", " << y << ", \"" << label << "\") 构造" << std::endl;
    }

    void display() const {
        std::cout << label << ": (" << x << ", " << y << ")" << std::endl;
    }
};

int main() {
    std::cout << "====== 默认构造函数 ======" << std::endl;

    Simple s1;           // 调用默认构造函数
    Simple s2 = Simple(); // 显式调用默认构造函数
    Simple s3{};          // C++11统一初始化语法

    s1.display();
    s2.display();
    s3.display();

    std::cout << "\n====== 带默认值的构造函数 ======" << std::endl;
    WithDefaults p1;           // 使用所有默认值
    WithDefaults p2(10);       // 只指定x
    WithDefaults p3(10, 20);   // 指定x和y
    WithDefaults p4(10, 20, "MyPoint"); // 指定所有参数

    p1.display();
    p2.display();
    p3.display();
    p4.display();

    return 0;
}
```

### 编译器生成的默认构造函数

如果类没有定义任何构造函数，编译器会自动生成一个默认构造函数（称为"合成的默认构造函数"）。这个合成构造函数会：
- 对于内置类型（int、double等）的成员，不进行初始化（值为未定义）。
- 对于类类型的成员，调用它们各自的默认构造函数。

```cpp
#include <iostream>
#include <string>

class AutoGenerated {
public:
    int intValue;        // 合成默认构造函数不会初始化
    double doubleValue;  // 合成默认构造函数不会初始化
    std::string strValue; // 合成默认构造函数会调用std::string的默认构造函数

    void display() const {
        std::cout << "intValue: " << intValue
                  << " (未初始化，可能是随机值)" << std::endl;
        std::cout << "doubleValue: " << doubleValue
                  << " (未初始化，可能是随机值)" << std::endl;
        std::cout << "strValue: \"" << strValue << "\" (已初始化为空字符串)" << std::endl;
    }
};

int main() {
    AutoGenerated obj;  // 使用编译器生成的默认构造函数
    obj.display();
    return 0;
}
```

### 显式声明默认构造函数

C++11允许使用`= default`显式要求编译器生成默认构造函数：

```cpp
#include <iostream>
#include <string>

class ExplicitDefault {
private:
    int value;
    std::string name;

public:
    // 显式要求编译器生成默认构造函数
    ExplicitDefault() = default;

    // 也可以显式删除默认构造函数
    // ExplicitDefault() = delete;

    void setValue(int v) { value = v; }
    void setName(const std::string& n) { name = n; }

    void display() const {
        std::cout << "value=" << value << ", name=" << name << std::endl;
    }
};

int main() {
    ExplicitDefault obj;
    obj.setValue(42);
    obj.setName("Hello");
    obj.display();
    return 0;
}
```

## 带参构造函数

带参构造函数允许在创建对象时提供初始值，确保对象以有效状态开始其生命周期。

```cpp
#include <iostream>
#include <string>
#include <cmath>

class Point3D {
private:
    double x, y, z;

public:
    // 默认构造函数
    Point3D() : x(0), y(0), z(0) {
        std::cout << "Point3D() 原点构造" << std::endl;
    }

    // 单参数构造函数
    explicit Point3D(double v) : x(v), y(v), z(v) {
        std::cout << "Point3D(" << v << ") 统一值构造" << std::endl;
    }

    // 三参数构造函数
    Point3D(double x, double y, double z) : x(x), y(y), z(z) {
        std::cout << "Point3D(" << x << ", " << y << ", " << z << ") 构造" << std::endl;
    }

    double distanceTo(const Point3D& other) const {
        double dx = x - other.x;
        double dy = y - other.y;
        double dz = z - other.z;
        return std::sqrt(dx * dx + dy * dy + dz * dz);
    }

    double magnitude() const {
        return std::sqrt(x * x + y * y + z * z);
    }

    void display() const {
        std::cout << "Point3D(" << x << ", " << y << ", " << z << ")" << std::endl;
    }
};

class Student {
private:
    std::string name;
    int age;
    double score;

public:
    // 构造函数：提供多种初始化方式
    Student() : name("未命名"), age(0), score(0.0) {}

    Student(const std::string& n) : name(n), age(0), score(0.0) {}

    Student(const std::string& n, int a) : name(n), age(a), score(0.0) {}

    Student(const std::string& n, int a, double s) : name(n), age(a), score(s) {}

    void display() const {
        std::cout << "Student: " << name << ", " << age
                  << "岁, 成绩: " << score << std::endl;
    }
};

int main() {
    std::cout << "====== 带参构造函数 ======" << std::endl;

    Point3D origin;              // 默认构造
    Point3D p1(5.0);             // 单参数构造 (explicit)
    Point3D p2(1.0, 2.0, 3.0);  // 三参数构造
    Point3D p3{10, 20, 30};      // 统一初始化语法

    origin.display();
    p1.display();
    p2.display();
    p3.display();

    std::cout << "p1到p2的距离: " << p1.distanceTo(p2) << std::endl;
    std::cout << "p3的模长: " << p3.magnitude() << std::endl;

    std::cout << "\n====== 学生对象 ======" << std::endl;
    Student s1;
    Student s2("张三");
    Student s3("李四", 20);
    Student s4("王五", 22, 95.5);

    s1.display();
    s2.display();
    s3.display();
    s4.display();

    return 0;
}
```

### explicit关键字

`explicit`关键字用于防止构造函数被用于隐式类型转换。通常建议将单参数构造函数声明为`explicit`，除非确实需要隐式转换：

```cpp
#include <iostream>
#include <string>

class Distance {
private:
    double meters;

public:
    // 不使用explicit：允许隐式转换
    // Distance(double m) : meters(m) {}

    // 使用explicit：禁止隐式转换
    explicit Distance(double m) : meters(m) {
        std::cout << "Distance(" << m << "m) 构造" << std::endl;
    }

    double getMeters() const { return meters; }
    double getKilometers() const { return meters / 1000.0; }
};

void printDistance(Distance d) {
    std::cout << d.getMeters() << " 米 = " << d.getKilometers() << " 公里" << std::endl;
}

int main() {
    Distance d1(1500.0);  // OK：直接初始化
    // Distance d2 = 2000.0;  // 错误：explicit禁止复制初始化
    Distance d3 = Distance(2000.0);  // OK：显式构造

    printDistance(Distance(3000.0));  // OK：显式构造
    // printDistance(3000.0);  // 错误：explicit禁止隐式转换

    printDistance(d1);
    printDistance(d3);

    return 0;
}
```

## 拷贝构造函数

### 浅拷贝的问题

拷贝构造函数用于创建一个对象的副本。如果类没有定义拷贝构造函数，编译器会生成一个合成拷贝构造函数，它执行的是**浅拷贝**（逐成员拷贝）。对于包含指针成员的类，浅拷贝会导致两个对象共享同一块动态内存，这非常危险。

```cpp
#include <iostream>
#include <cstring>

// 浅拷贝的问题演示
class ShallowString {
public:
    char* data;

    ShallowString(const char* str) {
        data = new char[strlen(str) + 1];
        strcpy(data, str);
        std::cout << "构造: " << data << std::endl;
    }

    // 编译器生成的拷贝构造函数（浅拷贝）
    // ShallowString(const ShallowString& other) : data(other.data) {}

    ~ShallowString() {
        std::cout << "析构: " << (data ? data : "null") << std::endl;
        delete[] data;
    }
};

int main() {
    std::cout << "====== 浅拷贝问题 ======" << std::endl;
    // 以下代码会导致double free错误！
    // ShallowString s1("Hello");
    // ShallowString s2 = s1;  // 浅拷贝：s1.data和s2.data指向同一块内存
    // 离开作用域时，s1和s2都会delete[] data，导致double free
    std::cout << "浅拷贝会导致double free错误，注释掉了实际代码" << std::endl;
    return 0;
}
```

### 深拷贝的实现

```cpp
#include <iostream>
#include <cstring>

class DeepString {
private:
    char* data;

public:
    // 构造函数
    DeepString(const char* str = "") {
        data = new char[strlen(str) + 1];
        strcpy(data, str);
        std::cout << "构造: \"" << data << "\"" << std::endl;
    }

    // 深拷贝构造函数
    DeepString(const DeepString& other) {
        data = new char[strlen(other.data) + 1];
        strcpy(data, other.data);
        std::cout << "拷贝构造: \"" << data << "\"" << std::endl;
    }

    // 赋值运算符（深拷贝）
    DeepString& operator=(const DeepString& other) {
        std::cout << "赋值运算符: \"" << data << "\" = \"" << other.data << "\"" << std::endl;
        if (this != &other) {
            delete[] data;
            data = new char[strlen(other.data) + 1];
            strcpy(data, other.data);
        }
        return *this;
    }

    // 析构函数
    ~DeepString() {
        std::cout << "析构: \"" << data << "\"" << std::endl;
        delete[] data;
    }

    const char* c_str() const { return data; }
    size_t length() const { return strlen(data); }

    // 修改字符串
    void set(const char* str) {
        delete[] data;
        data = new char[strlen(str) + 1];
        strcpy(data, str);
    }
};

int main() {
    std::cout << "====== 深拷贝演示 ======" << std::endl;

    DeepString s1("Hello World");
    DeepString s2 = s1;  // 调用拷贝构造函数（深拷贝）
    DeepString s3("Temp");
    s3 = s1;             // 调用赋值运算符（深拷贝）

    std::cout << "\ns1: " << s1.c_str() << std::endl;
    std::cout << "s2: " << s2.c_str() << std::endl;
    std::cout << "s3: " << s3.c_str() << std::endl;

    // 修改s2不影响s1
    s2.set("Modified");
    std::cout << "\n修改s2后:" << std::endl;
    std::cout << "s1: " << s1.c_str() << std::endl;
    std::cout << "s2: " << s2.c_str() << std::endl;

    std::cout << "\n====== 程序结束 ======" << std::endl;
    return 0;
}
```

### 拷贝构造函数的调用时机

拷贝构造函数在以下场景中被调用：

1. 用一个对象初始化另一个对象（`ClassName obj2 = obj1;`）
2. 将对象作为值传递给函数参数
3. 函数返回值为对象（非引用）

```cpp
#include <iostream>

class Tracker {
private:
    int id;
    static int counter;

public:
    Tracker() : id(++counter) {
        std::cout << "Tracker #" << id << " 默认构造" << std::endl;
    }

    Tracker(const Tracker& other) : id(++counter) {
        std::cout << "Tracker #" << id << " 拷贝构造(来自 #" << other.id << ")" << std::endl;
    }

    ~Tracker() {
        std::cout << "Tracker #" << id << " 析构" << std::endl;
    }

    int getId() const { return id; }
};

int Tracker::counter = 0;

// 值传递：触发拷贝构造
void passByValue(Tracker t) {
    std::cout << "passByValue: 收到 Tracker #" << t.getId() << std::endl;
}

// 值返回：可能触发拷贝构造（编译器可能优化为NRVO）
Tracker returnByValue() {
    Tracker t;
    std::cout << "returnByValue: 创建 Tracker #" << t.getId() << std::endl;
    return t;
}

int main() {
    std::cout << "====== 拷贝构造调用时机 ======" << std::endl;

    std::cout << "\n1. 对象初始化另一个对象:" << std::endl;
    Tracker t1;
    Tracker t2 = t1;  // 拷贝构造
    Tracker t3(t1);   // 拷贝构造（直接初始化）

    std::cout << "\n2. 值传递:" << std::endl;
    passByValue(t1);  // 拷贝构造

    std::cout << "\n3. 值返回:" << std::endl;
    Tracker t4 = returnByValue();  // 可能触发拷贝构造（或NRVO优化）

    std::cout << "\n====== main函数结束 ======" << std::endl;
    return 0;
}
```

## 移动构造函数

移动构造函数是C++11引入的重要特性，它通过"窃取"临时对象的资源来避免不必要的深拷贝，从而显著提升性能。

```cpp
#include <iostream>
#include <cstring>
#include <utility>
#include <vector>
#include <chrono>

class MoveString {
private:
    char* data;
    size_t length;

public:
    // 默认构造函数
    MoveString() : data(nullptr), length(0) {
        std::cout << "默认构造" << std::endl;
    }

    // 带参构造函数
    MoveString(const char* str) {
        length = strlen(str);
        data = new char[length + 1];
        strcpy(data, str);
        std::cout << "构造: \"" << data << "\"" << std::endl;
    }

    // 拷贝构造函数
    MoveString(const MoveString& other) {
        length = other.length;
        data = new char[length + 1];
        strcpy(data, other.data);
        std::cout << "拷贝构造: \"" << data << "\"" << std::endl;
    }

    // 移动构造函数（noexcept很重要！）
    MoveString(MoveString&& other) noexcept {
        // 窃取资源
        data = other.data;
        length = other.length;
        // 将源对象置于安全状态
        other.data = nullptr;
        other.length = 0;
        std::cout << "移动构造: \"" << (data ? data : "null") << "\"" << std::endl;
    }

    // 拷贝赋值运算符
    MoveString& operator=(const MoveString& other) {
        std::cout << "拷贝赋值" << std::endl;
        if (this != &other) {
            delete[] data;
            length = other.length;
            data = new char[length + 1];
            strcpy(data, other.data);
        }
        return *this;
    }

    // 移动赋值运算符
    MoveString& operator=(MoveString&& other) noexcept {
        std::cout << "移动赋值" << std::endl;
        if (this != &other) {
            delete[] data;
            data = other.data;
            length = other.length;
            other.data = nullptr;
            other.length = 0;
        }
        return *this;
    }

    // 析构函数
    ~MoveString() {
        if (data) {
            std::cout << "析构: \"" << data << "\"" << std::endl;
            delete[] data;
        } else {
            std::cout << "析构: (null)" << std::endl;
        }
    }

    const char* c_str() const { return data ? data : "(null)"; }
    size_t size() const { return length; }
};

// 创建临时对象并返回
MoveString createString() {
    MoveString temp("Temporary String");
    return temp;  // 触发移动构造（或NRVO）
}

int main() {
    std::cout << "====== 移动构造演示 ======" << std::endl;

    std::cout << "\n--- 基本移动构造 ---" << std::endl;
    MoveString s1("Hello");
    MoveString s2 = std::move(s1);  // 强制使用移动构造
    std::cout << "s1: " << s1.c_str() << std::endl;  // s1已被移空
    std::cout << "s2: " << s2.c_str() << std::endl;

    std::cout << "\n--- 函数返回时移动 ---" << std::endl;
    MoveString s3 = createString();  // 移动构造（或NRVO）
    std::cout << "s3: " << s3.c_str() << std::endl;

    std::cout << "\n--- 移动赋值 ---" << std::endl;
    MoveString s4("World");
    s4 = std::move(s3);  // 移动赋值
    std::cout << "s3: " << s3.c_str() << std::endl;
    std::cout << "s4: " << s4.c_str() << std::endl;

    std::cout << "\n====== 程序结束 ======" << std::endl;
    return 0;
}
```

## 析构函数

析构函数在对象生命周期结束时自动调用，负责释放对象占用的资源。析构函数没有参数，没有返回值，不能被重载。

```cpp
#include <iostream>
#include <string>
#include <fstream>

class FileWriter {
private:
    std::ofstream file;
    std::string filename;

public:
    FileWriter(const std::string& fname) : filename(fname) {
        file.open(filename);
        if (file.is_open()) {
            std::cout << "文件 \"" << filename << "\" 已打开" << std::endl;
        }
    }

    // 析构函数：自动关闭文件
    ~FileWriter() {
        if (file.is_open()) {
            file.close();
            std::cout << "文件 \"" << filename << "\" 已关闭" << std::endl;
        }
    }

    void write(const std::string& content) {
        if (file.is_open()) {
            file << content << std::endl;
            std::cout << "写入: " << content << std::endl;
        }
    }

    bool isOpen() const { return file.is_open(); }
};

class ResourceManager {
private:
    int* data;
    size_t size;
    std::string name;

public:
    ResourceManager(const std::string& n, size_t s)
        : name(n), size(s) {
        data = new int[size];
        for (size_t i = 0; i < size; i++) {
            data[i] = static_cast<int>(i);
        }
        std::cout << "ResourceManager \"" << name << "\" 分配了 " << size << " 个int" << std::endl;
    }

    // 析构函数：释放资源
    ~ResourceManager() {
        delete[] data;
        std::cout << "ResourceManager \"" << name << "\" 释放了资源" << std::endl;
    }

    void display() const {
        std::cout << name << ": ";
        for (size_t i = 0; i < size && i < 10; i++) {
            std::cout << data[i] << " ";
        }
        std::cout << std::endl;
    }
};

int main() {
    std::cout << "====== 析构函数演示 ======" << std::endl;

    {
        std::cout << "\n进入作用域" << std::endl;
        FileWriter fw("test_output.txt");
        if (fw.isOpen()) {
            fw.write("Hello, RAII!");
            fw.write("This file will be automatically closed.");
        }
        ResourceManager rm("MyData", 100);
        rm.display();
        std::cout << "离开作用域（析构函数将自动调用）" << std::endl;
    }  // fw和rm的析构函数在这里自动调用

    std::cout << "\n====== 程序结束 ======" << std::endl;
    return 0;
}
```

## 初始化列表

初始化列表是C++中初始化成员变量的推荐方式，它比在构造函数体内赋值更高效，特别是对于const成员、引用成员和类类型成员。

```cpp
#include <iostream>
#include <string>

class InitListDemo {
private:
    const int constValue;       // const成员必须用初始化列表
    int& refValue;              // 引用成员必须用初始化列表
    std::string name;
    int normalValue;

public:
    // 使用初始化列表初始化所有成员
    InitListDemo(int cv, int& rv, const std::string& n, int nv)
        : constValue(cv)       // 初始化const成员

        , name(n)              // 初始化std::string（比赋值更高效）

    {
        // 构造函数体：此时所有成员已经初始化完毕
        std::cout << "InitListDemo 构造完成" << std::endl;
    }

    void display() const {
        std::cout << "constValue: " << constValue << std::endl;
        std::cout << "refValue: " << refValue << std::endl;
        std::cout << "name: " << name << std::endl;
        std::cout << "normalValue: " << normalValue << std::endl;
    }
};

// 初始化列表 vs 构造函数体内赋值
class PerformanceDemo {
```

### 初始化列表的初始化顺序

成员变量的初始化顺序由它们在类中的声明顺序决定，而不是初始化列表中的顺序。这个特性非常重要，如果初始化列表中的顺序与声明顺序不一致，可能导致难以发现的Bug。

```cpp
#include <iostream>

class OrderDemo {
private:
    int first;
    int second;
    int third;

public:
    // 警告：初始化顺序由声明顺序决定，不是初始化列表顺序！
    OrderDemo(int val)
        : third(val)       // 实际第三个初始化
        , second(third + 1) // 实际第二个初始化（但third还未初始化！）
        , first(second + 1) // 实际第一个初始化（但second还未初始化！）
    {
        std::cout << "构造完成" << std::endl;
    }

    void display() const {
        std::cout << "first=" << first
                  << ", second=" << second
                  << ", third=" << third << std::endl;
        std::cout << "注意：值可能不是预期的，因为初始化顺序与声明顺序一致" << std::endl;
    }
};

// 正确的做法：初始化列表顺序与声明顺序一致
class CorrectOrder {
private:
    int first;
    int second;
    int third;

public:
    CorrectOrder(int val)
        : first(val)        // 第一个初始化
        , second(first + 1) // 第二个初始化
        , third(second + 1) // 第三个初始化
    {
        std::cout << "CorrectOrder 构造完成" << std::endl;
    }

    void display() const {
        std::cout << "first=" << first
                  << ", second=" << second
                  << ", third=" << third << std::endl;
    }
};

int main() {
    std::cout << "====== 初始化顺序 ======" << std::endl;
    OrderDemo wrong(10);
    wrong.display();

    std::cout << std::endl;
    CorrectOrder correct(10);
    correct.display();

    return 0;
}
```

## 委托构造函数

委托构造函数是C++11引入的特性，允许一个构造函数调用同一个类的另一个构造函数，从而避免代码重复。

```cpp
#include <iostream>
#include <string>

class Employee {
private:
    std::string name;
    int id;
    std::string department;
    double salary;
    std::string hireDate;

public:
    // 主构造函数：最完整的版本
    Employee(const std::string& n, int i, const std::string& dept,
             double sal, const std::string& date)
        : name(n), id(i), department(dept), salary(sal), hireDate(date) {
        std::cout << "主构造函数: " << name << " (ID: " << id << ")" << std::endl;
    }

    // 委托构造函数：只指定姓名和ID，其他使用默认值
    Employee(const std::string& n, int i)
        : Employee(n, i, "未分配", 0.0, "未指定") {
        std::cout << "  委托构造(姓名+ID)" << std::endl;
    }

    // 委托构造函数：姓名、ID和部门
    Employee(const std::string& n, int i, const std::string& dept)
        : Employee(n, i, dept, 0.0, "未指定") {
        std::cout << "  委托构造(姓名+ID+部门)" << std::endl;
    }

    // 委托构造函数：姓名、ID、部门、薪资
    Employee(const std::string& n, int i, const std::string& dept, double sal)
        : Employee(n, i, dept, sal, "未指定") {
        std::cout << "  委托构造(姓名+ID+部门+薪资)" << std::endl;
    }

    void display() const {
        std::cout << "  员工信息: " << name
                  << " | ID: " << id
                  << " | 部门: " << department
                  << " | 薪资: ¥" << salary
                  << " | 入职日期: " << hireDate << std::endl;
    }
};

int main() {
    std::cout << "====== 委托构造函数 ======" << std::endl;

    std::cout << "\n创建员工1:" << std::endl;
    Employee e1("张三", 1001);
    e1.display();

    std::cout << "\n创建员工2:" << std::endl;
    Employee e2("李四", 1002, "技术部");
    e2.display();

    std::cout << "\n创建员工3:" << std::endl;
    Employee e3("王五", 1003, "市场部", 8000.0);
    e3.display();

    std::cout << "\n创建员工4:" << std::endl;
    Employee e4("赵六", 1004, "研发部", 15000.0, "2024-03-15");
    e4.display();

    return 0;
}
```

## 综合示例：完整的String类

下面是一个综合示例，展示了构造函数、析构函数、拷贝/移动构造、初始化列表等所有概念：

```cpp
#include <iostream>
#include <cstring>
#include <utility>

class MyString {
private:
    char* data;
    size_t length;

public:
    // 默认构造函数
    MyString() : data(nullptr), length(0) {}

    // C字符串构造函数
    MyString(const char* str) : data(nullptr), length(0) {
        if (str) {
            length = std::strlen(str);
            data = new char[length + 1];
            std::strcpy(data, str);
        }
    }

    // 拷贝构造函数
    MyString(const MyString& other) : data(nullptr), length(0) {
        if (other.data) {
            length = other.length;
            data = new char[length + 1];
            std::strcpy(data, other.data);
        }
    }

    // 移动构造函数
    MyString(MyString&& other) noexcept
        : data(other.data), length(other.length) {
        other.data = nullptr;
        other.length = 0;
    }

    // 拷贝赋值运算符
    MyString& operator=(const MyString& other) {
        if (this != &other) {
            delete[] data;
            data = nullptr;
            length = 0;
            if (other.data) {
                length = other.length;
                data = new char[length + 1];
                std::strcpy(data, other.data);
            }
        }
        return *this;
    }

    // 移动赋值运算符
    MyString& operator=(MyString&& other) noexcept {
        if (this != &other) {
            delete[] data;
            data = other.data;
            length = other.length;
            other.data = nullptr;
            other.length = 0;
        }
        return *this;
    }

    // 析构函数
    ~MyString() {
        delete[] data;
    }

    // 运算符重载
    MyString operator+(const MyString& other) const {
        MyString result;
        result.length = length + other.length;
        result.data = new char[result.length + 1];
        if (data) std::strcpy(result.data, data);
        if (other.data) std::strcat(result.data, other.data);
        return result;
    }

    bool operator==(const MyString& other) const {
        if (length != other.length) return false;
        if (!data && !other.data) return true;
        if (!data || !other.data) return false;
        return std::strcmp(data, other.data) == 0;
    }

    // 访问器
    const char* c_str() const { return data ? data : ""; }
    size_t size() const { return length; }
    bool empty() const { return length == 0; }

    // 修改器
    void clear() {
        delete[] data;
        data = nullptr;
        length = 0;
    }

    void append(const char* str) {
        if (!str) return;
        *this = *this + MyString(str);
    }
};

int main() {
    std::cout << "====== MyString 综合演示 ======" << std::endl;

    // 构造
    MyString s1("Hello");
    MyString s2(" World");
    MyString s3 = s1;           // 拷贝构造
    MyString s4 = std::move(s1); // 移动构造

    std::cout << "s1: \"" << s1.c_str() << "\" (已被移动)" << std::endl;
    std::cout << "s2: \"" << s2.c_str() << "\"" << std::endl;
    std::cout << "s3: \"" << s3.c_str() << "\" (拷贝自s1)" << std::endl;
    std::cout << "s4: \"" << s4.c_str() << "\" (移动自s1)" << std::endl;

    // 连接
    MyString s5 = s3 + s2;
    std::cout << "s3 + s2: \"" << s5.c_str() << "\"" << std::endl;

    // 比较
    std::cout << "s3 == s4? " << (s3 == s4 ? "true" : "false") << std::endl;

    // 追加
    s5.append("!!!");
    std::cout << "s5 after append: \"" << s5.c_str() << "\"" << std::endl;

    return 0;
}
```

## 总结

本文详细介绍了C++类与对象的构造函数和析构函数，涵盖了从基础到高级的各种特性。

### 核心要点回顾

1. **默认构造函数**：无参或所有参数都有默认值的构造函数。如果类没有定义任何构造函数，编译器会生成一个合成默认构造函数。C++11支持`= default`和`= delete`来显式控制默认构造函数的生成。

2. **带参构造函数**：允许在创建对象时提供初始值。`explicit`关键字可以防止单参数构造函数被用于隐式类型转换。

3. **拷贝构造函数**：用于创建对象的副本。浅拷贝会导致指针成员共享同一块内存，可能引发double free错误。深拷贝为指针成员分配独立的内存，保证对象之间的独立性。

4. **移动构造函数**：C++11引入的特性，通过"窃取"临时对象的资源来避免深拷贝。移动构造函数通常标记为`noexcept`以确保容器在重新分配时使用移动而非拷贝。

5. **析构函数**：在对象生命周期结束时自动调用，用于释放资源。析构函数无参无返回值，不能被重载。析构函数是RAII的核心。

6. **初始化列表**：推荐使用初始化列表而非构造函数体内赋值来初始化成员变量。const成员、引用成员和没有默认构造函数的类类型成员必须使用初始化列表。初始化顺序由声明顺序决定，而非初始化列表中的顺序。

7. **委托构造函数**：C++11特性，允许一个构造函数调用同一个类的另一个构造函数，减少代码重复。
