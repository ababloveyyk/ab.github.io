# AWD 攻防演练入门

## 什么是 AWD

AWD（Attack With Defense）是一种攻防实战演练模式，参赛队伍同时拥有攻击和防守的任务。

## AWD 比赛流程

### 准备阶段

- 了解比赛规则和评分机制
- 搭建本地环境进行练习
- 准备工具和脚本

### 攻击阶段

- 发现其他队伍的漏洞
- 利用漏洞获取 flag
- 提交 flag 获得分数

### 防守阶段

- 修复自己服务器的漏洞
- 加固防护措施
- 监控异常流量

## 核心技能

### 漏洞挖掘

快速发现和利用漏洞是攻击成功的关键。

### 漏洞修复

及时修复漏洞，防止被其他队伍攻击。

### 应急响应

当服务器被入侵时，快速定位问题并恢复。

### 团队协作

AWD 是团队比赛，需要成员之间的良好配合。

## 常用工具

- **nmap**：端口扫描工具
- **Burp Suite**：Web 安全测试工具
- **Metasploit**：漏洞利用框架
- **Wireshark**：网络流量分析工具
- **Fail2ban**：入侵防护工具

## 实战建议

- 参加线上 AWD 比赛积累经验
- 学习蓝队防守技巧
- 关注安全事件响应案例
