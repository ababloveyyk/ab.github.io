# 网络安全入门

## 什么是网络安全

网络安全是指保护计算机网络免受未经授权的访问、使用、披露、破坏、修改或拒绝服务的技术和实践。

## 网络安全层次

### 物理层安全

保护网络设备和基础设施的物理安全。

### 网络层安全

保护网络通信的安全，包括防火墙、入侵检测等。

### 应用层安全

保护应用程序和数据的安全，包括 Web 安全、API 安全等。

### 数据层安全

保护数据的机密性、完整性和可用性。

## 核心概念

### TCP/IP 协议

TCP/IP 是互联网的基础协议，了解它是学习网络安全的前提。

### 防火墙

防火墙是网络安全的第一道防线，用于控制网络流量。

### 入侵检测系统（IDS）

IDS 用于检测和告警可疑的网络活动。

### 入侵防御系统（IPS）

IPS 在检测到攻击时可以主动阻止攻击。

## 学习路径

1. **基础阶段**：计算机网络基础、TCP/IP 协议
2. **中级阶段**：防火墙配置、入侵检测、网络流量分析
3. **高级阶段**：渗透测试、安全评估、应急响应

## 常用工具

- **Wireshark**：网络流量分析工具
- **tcpdump**：命令行抓包工具
- **nmap**：端口扫描工具
- **Snort**：开源 IDS
- **Suricata**：高性能 IDS/IPS
