## 这个博客到底写啥？

**写给面试官看，但更是写给 30 岁以后的自己看。**

我会把每天学到的东西写成 **正经教程**（毕竟不能误人子弟），但行文里可能夹带私货——比如吐槽某个漏洞蠢得可爱，或者某条命令又把我电脑搞崩了。
当作技术日记，不追求流量，只求以后翻到能想起"哦，那天我调这个 bug 调到凌晨三点"。
