    # 待办事项应用

    一个简单的待办事项管理应用。

    # 功能需求

    • 添加待办事项
    • 标记完成状态
    • 删除待办事项
    • 筛选显示
    • 数据持久化

    # 技术实现

    class TodoApp {
  constructor() {
    this.todos = []
  }
  
  addTodo(text) {
    this.todos.push({
      id: Date.now(),
      text,
      completed: false
    })
  }
  
  toggleTodo(id) {
    const todo = this.todos.find(t => t.id === id)
    if (todo) {
      todo.completed = !todo.completed
    }
  }
}
